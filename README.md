# もじたま！

公開ページ：<https://mochi8989.github.io/mojitama/>

タイピングでコインを集め、たまごからペットを育てるゲームです。広告・課金・アカウント登録はありません。
ZIPをすべて展開して index.html を開いてください。継続して遊ぶ場合は同じブラウザ・配信元を使ってください。GitHub Pages はフォルダーの中身をそのまま配置します。ローカル配信はこのフォルダーで以下を実行し、http://127.0.0.1:8000/ を開きます。

    python3 -m http.server 8000 --bind 127.0.0.1

## タイピング
練習コースは「あいうえお」「ローマじ」「ことば」「ながい ことば」「ぶん」の5つで、最初からすべて選べます。画面のキーでも遊べます。通常665件のうち535件が単語、残りはかな・短文です。おもしろ213件を含め全878件。初期設定は「なし」。0・25・70・100％を選べ、変更は次の問題からです。かな練習はかなだけです。レア問題はおもしろ側に含み、対象が残っているときに抽選されます。重複回避を優先するため、割合はコースや残数によって変わります。復習による再出題はありません。

コースとジャンルごとの袋から一度ずつ引き、使い切ったらシャッフルします。コース5の70％設定では100問につき、うんち系25・ダジャレ15・ミーム系20・かわいい系10・通常30の順不同です。出題履歴は端末内に保存します。旧版から育成記録は引き継ぎ、旧方式の抽選履歴だけは新しい袋で始めます。ABC／abc／Abc（頭文字だけ大文字）表示は途中で変更でき、入力は大文字小文字を区別しません。Shiftは不要です。SHI/SIなどどちらでも進み、ガイドは入力した綴りに追従します。通常正解はコース1から順に10・15・20・25・30コイン、レア問題はその5倍です。ノーミス連続5問で追加10、10問で追加20コインです。

## ペット
その子と5問正解で孵化し、累計1・4・12回のお世話で進化します。おとなもお世話できます。最初の子は図鑑で種類を選べます。ふみきり・しつがいき・せんぷうきも選べます。購入した卵の種類は固定で、孵化前はたまごとして育てます。ふつうのたまごは300コイン、レアなたまごは1000コインで、候補は購入前に表示します。今の子は購入時におへやで保管され、無料で交代できます。

おとなのペットは、いつでも一緒にいるか「旅に出す」かを選べます。旅に出す前に確認し、一度だけ500コインと記念メダルを受け取り、旅のおもいでアルバムからPNGを保存できます。旧版には育成開始日がないため、その子のアルバムでは「開始日ふめい」と表示します。旅に出した数1・3・10匹と、卵屋の全10種類を旅に出すと実績が付きます。正解数、最高記録、コースごとの記録などはプレイヤー全体で引き継ぎます。旅に出した直後もタイピングでコインを集められます。ローカル保存のため、ブラウザのデータ削除や別の配信元への移動では記録を引き継げません。

## 運営者向け：単語管理
編集元は data/words.json です。公開画面には編集・送信機能がありません。変更はリポジトリの書き込み権限を持つ運営者がコミットしてください。既存IDは変更・再使用しないでください。必要な項目は id、display、reading（ひらがな）、romaji、category、difficulty（1〜5）、length（標準ローマ字長）、kind（normal/fun）。レアだけ rare:true。ローマ字と長さは roman.js の standard(reading) から求めます。

    node tools/validate.cjs --build
    node tests/questions.cjs
    node tests/family.cjs

--build はローマ字・重複・件数などを検証し、ファイル直接起動用の data/offline.js を再生成します。JSONと一緒にコミットしてください。HTTPではJSONを直接読み、ゲーム本体の修正や生成物は不要です。
ブラウザ統合テストは Playwright と Chromium を用意して node tests/browser.cjs を実行します。CHROME_PATH でChromeの実行ファイルを指定できます。既定はファイル直接起動、GAME_URL で同じ内容のローカル配信先も検証できます。テストは専用の一時プロファイルを使います。

## おもしろことばの選定
動画・ゲームは、ボタン、撮影道具、協力プレイなど、言葉だけで説明できるものを中心にしました。外部サイトへの誘導、チャット、第三者の画像・音源・動画は収録していません。動画用語は [YouTube ヘルプ](https://support.google.com/youtube/answer/57792?hl=ja) の用例を参照しました。「それな」（同意）と「エッホエッホ」（走る姿をまねた掛け声）は[小学館の小学生調査](https://prtimes.jp/main/html/rd/p/000000018.000140019.html) を参考に文字だけを採用。「ひき肉です」は[進研ゼミの調査](https://benesse.jp/kosodate/202312/20231222-1.html)で特定の人のあいさつと確認できるため今回は見送りました。軽いおどけた語や擬音は任意のON設定に限定します。既存のペットや効果音の設定は別に維持します。

保護者向けの閲覧ページの設計は TASKS.md にあります。

## 第12弾の表記・入力
[文化庁の令和7年内閣告示](https://www.bunka.go.jp/kokugo_nihongo/sisaku/joho/joho/kijun/naikaku/roma/index2.html) と [文部科学省の解説更新](https://www.mext.go.jp/magazine/backnumber/1422844_00193.htm) を参照しています。本作はキーボードで読みを入力する練習です。推奨ガイドは SHI・CHI・TSU・CHA を優先しますが、かなの「こう」は KOU、長音符はハイフンで入力します。公的なローマ字表記そのものを採点する教材ではありません。SI・TI・TU・TYA などの入力経路も同じ報酬です。length は推奨キー列の長さです。

追加問題は added=2026-11 で抽出できます。確認した名称は source に出典、オリジナルやダジャレは origin に区分を持ちます。画像・音声はミーム問題に使用しません。ペットのドット絵は adult.js が32×32の配列として生成します。旅立ちの直後、その画面から300または1000コインで次の卵を選べます。
