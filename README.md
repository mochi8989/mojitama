# もじたま！
時間制限のないタイピングで、たまごから白いペットを育てるゲームです。登録・課金・広告・外部通信はありません。

## あそびかた
黄色のキーを、ピンク色の指で押します。画面上のキーも使えます。1問10コイン。ノーミス5問で追加10、10問で追加20コインです。ミスしても手持ちのコインは減りません。おせわショップでは商品を選ぶとその場で使います。通算3問正解すると自動でたまごがかえります。以前の記録のペットも引き継ぎます。

お世話1回で経験値10。孵化後は累計4・12回のお世話で進化します。累計5・15・30・50問で練習レベルが順に開き、進化でも一部が早く開きます。練習画面で好きなレベルを選べます。放置してもペットはいなくなりません。

## 起動
ZIPをすべて展開して index.html をブラウザで開いてください。安定した自動保存にはローカル配信を推奨します。Python 3 がある場合は展開した mojitama フォルダーで次を実行し、同じブラウザで http://localhost:8000/ を開きます。
```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

## 自動セーブ
コイン、正解数、お世話・成長、練習レベル、音の設定は状態が変わるたびに localStorage に保存します。旧版の同じ保存キーを引き継ぎ、破損値は既定値に戻します。ブラウザ、プロファイル、URLの配信元を変えると別の記録になります。プライベート閲覧の終了やブラウザのデータ削除で失われることがあります。ファイルを直接開いた場合の保存動作はブラウザに依存します。

## GitHub Pages
公開する場合はこのフォルダーの中身をリポジトリの main ブランチ直下に配置し、Settings → Pages → Deploy from a branch で main / (root) を指定します。ビルド不要です。ファイル参照はすべて相対パスです。

## ファイル
index.html：画面、style.css：配色とアニメーション、sprites.js：付属版から引き継いだドット絵、game.js：入力・指ガイド・ショップ・育成・保存・音声。

今後の候補：合言葉による引き継ぎ、進化分岐、模様替え。

レア問題は選択レベルのローマ字長に合う候補がある場合だけ、各問3%で出題します。基本報酬50コインに既存の連続ボーナスを加算します。大当たり音はWeb Audioで合成します。

ホームのペットの下で「ごはん」「あそぶ」「おふろ」を選べます。追加アイテムは「もっと おせわする」にあります。正解5問ごとに各ステータスが5ずつ減り、40以下になるとお世話のリクエストが出ます。

「📸 しゃしんを とる」から、1200×1200のペットカード・きろくカードを端末内で作れます。メダルは累計1・10・50問、最高スコアはミスなしで連続正解した問題数です。旧セーブのメダルは累計から復元し、最高記録は機能追加後から計測します。
